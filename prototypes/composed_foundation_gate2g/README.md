# Composed Foundation Gate 2G

This final prototype gate synthesizes Gates 1 through 2F against the approved
architecture-driver rubric in issue #10 and the evidence requested by issue
#11. It answers foundation viability only; it does not admit dependencies or
approve production architecture.

Run from the repository root:

```bash
./prototypes/composed_foundation_gate2g/run-gate2g.sh
```

The verifier checks that every issue-evidence category, architecture-driver
group, and selection dimension has one explicit disposition and a valid
primary-evidence pointer. Its output is written outside the worktree by
default.
