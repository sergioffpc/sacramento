a Sacramento-owned versioned protocol through a GameNetworkingSockets adapter
while a Debian Session Authority advances at a fixed canonical tick and
reproduces an exact digest independently of connection and packet arrival order?

This is throwaway Gate 2C evidence on `prototype/composed-foundation-spine`.
It must not merge into `develop`.

Run:

```sh
prototypes/composed_foundation_gate2c/run-gate2c.sh
```

The gate is deliberately limited to loopback connection/transport, protocol
encoding, deterministic input ordering, fixed integer state updates, and exact
replay evidence. It is not a production networking, Admission, recovery,
prediction, relevance, congestion, or security implementation.
